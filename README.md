# Fundação Do OpenerNinja
A fundação openerninja um Mini sistema operacional 🚀🚀

Um aplicativo suportado somente para Windows 

## Funções

# Linguagem Agm Auto Gui Machine
Sistema possui a linguagem Agm Auto Gui Machine Versão:GV1.00g

### Regras da linguagem Agm
<app_create> # necessário nunca esqueça desse parser 

<app_name> (nome do aplicativo) # Também necessário 

<app_scroll> somente necessário se elementos não caberem no quadro

###### Por exemplo:
<app_create>
<app_name> (Meu Projeto em agm)

Salve esse arquivo com qualquer nome pode ser: main.agm, Clique duas vezes nele, cadastre na sua conta, e vai aparecer uma janela.

##### Como desenhar textos 
Você vai utiliza o parser <app_text> 
###### Uma base disso
<app_create>
<app_name> (Meu Projeto em agm)

<app_text> # inclui os textos sempre coloque caso precise adicionar textos
line1_text= L Olá mundo. ) # adicionará um texto escrito Olá mundo no quadro
