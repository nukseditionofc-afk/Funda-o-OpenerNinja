# Linguagem Agm Auto Gui Machine
Sistema possui a linguagem Agm Auto Gui Machine Versão:GV1.00g

### Regras necessárias da linguagem Agm
<app_create> # necessário nunca esqueça desse parser 

<app_name> (nome do aplicativo) # Também necessário 

<app_scroll> # somente necessário se o seub projeto possuir muitas linhas de elementos
###### Por exemplo:
<app_create><br>
<app_name> (Meu Projeto em agm)

Salve esse arquivo com qualquer nome pode ser: main.agm, Clique duas vezes nele, cadastre na sua conta, e vai aparecer uma janela.

##### Como desenhar textos 
Você vai utiliza o parser <app_text> 
###### Uma base disso
###### Parsers necessários
<app_create><br>
<app_name>(Agm Testes)<br>
<app_scroll><br>
###### nota sempre pule uma linha quando incluir elementos você nunca vai pular para os parsers necessários 

<app_text><br>
line1_text=L Ola mundo. >
